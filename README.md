# To-Do List

A simple console-based To-Do List application developed using Java.

## Features

- Add a new task
- View all tasks
- Mark a task as completed
- Delete a task
- Exit the application

## Technologies Used

- Java
- ArrayList
- Scanner
- Object-Oriented Programming

## How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Run ToDoList.java.
4. Choose an option from the menu.

## Menu

```text
===== TO-DO LIST =====
1. Add Task
2. View Tasks
3. Complete Task
